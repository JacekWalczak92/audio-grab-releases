# AudioGrab – wydania

Tu trafiają gotowe pliki APK aplikacji **AudioGrab** (Android 10+), która nagrywa dźwięk
odtwarzany przez telefon lub tablet do plików M4A, z wykrywaniem ciszy i podziałem na pliki.

## Pobieranie

Najnowszy plik `AudioGrab_vN.apk` jest w zakładce
[Releases](https://github.com/JacekWalczak92/audio-grab-releases/releases/latest).

## Obtainium

1. W Obtainium wybierz **Dodaj aplikację**.
2. Wklej adres: `https://github.com/JacekWalczak92/audio-grab-releases`
3. Zostaw ustawienia domyślne i zatwierdź. Obtainium pobierze APK z najnowszego wydania
   i będzie pokazywać aktualizacje, gdy pojawi się nowy tag `vN`.
